# getswarmbot.com

Landing page for [Swarm for Synology](https://github.com/vbcnv/synology-monitor). One static page, no build step.

- `index.html`: the page. The bee is the original vector artwork, inlined as SVG and animated with GSAP MorphSVG (loaded from jsDelivr).
- `screens/`: portal screenshots from the repository's demo fleet (made-up customers).
- `CNAME`: for GitHub Pages.

Preview locally with any static server, for example `python3 -m http.server`.
